## Try Kolibri before you install

Learning Equality's live demo runs the current release (0.19.5). Click **Explore without account** to browse the library as a learner. The demo doesn't publish coach or admin logins, so practice those roles on the class server.

- **[Open Kolibri demo](https://kolibri-demo.learningequality.org/en/auth/#/signin)**
- **[Browse content catalog](https://kolibri-catalog-en.learningequality.org/en/learn/)**
